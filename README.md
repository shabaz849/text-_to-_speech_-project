# 🔊 Text-to-Speech Converter

## 📌 About the Project
The Text-to-Speech Converter is a Python-based web application built using Streamlit and Google Text-to-Speech (gTTS). It converts written text into spoken audio and allows users to listen to and download the generated speech as MP3 files.

## ✨ Features
- Convert text into speech.
- Support multiple languages.
- Listen to generated audio online.
- Download speech as an MP3 file.
- Simple and user-friendly interface.
- Input validation and error handling.

## 🛠️ Technologies Used
- Python
- Streamlit
- Google Text-to-Speech (gTTS)
- Google Colab
- Pyngrok (for public access)

## 🌐 Supported Languages
- English
- Hindi
- Kannada
- Urdu
- Arabic
- Spanish
- French
- German
- Italian

## 📦 Installation

Install the required libraries:

```bash
pip install streamlit gTTS pyngrok
```

## ▶️ Run the Application

Save the application code as `app.py` and run:

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal, usually `http://localhost:8501`.

## 🚀 How to Use
1. Open the application.
2. Enter text in the input box.
3. Select your preferred language.
4. Click **Generate Speech**.
5. Listen to the generated audio.
6. Click **Download MP3** to save the audio.
